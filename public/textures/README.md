Fuente y créditos: NASA's Scientific Visualization Studio, CGI Moon Kit; Ernie Wright; datos LRO/LROC y LOLA.
https://svs.gsfc.nasa.gov/4720/

Mapa equirectangular centrado en 0° de longitud, norte arriba. Los huecos polares de la imagen se completan a partir de albedo de LOLA. NASA identifica este recurso como optimizado para estética, no para ciencia. Se utiliza exclusivamente para renderizar la esfera; no es un modelo de terreno ni una entrada del futuro motor científico.
